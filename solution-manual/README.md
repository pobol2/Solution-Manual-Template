# solution-manual

Shared classes and build rules for the [Solution Manual Template](../README.md).
Projects customize these through their own files and never edit this folder.
[`site/`](site/) holds the website builder, configured by each project's
`site/site.toml` (see [Website](../docs/website.md)).

See [Using the framework in another project](../docs/advanced-submodule.md) for
setup, submodules, migration and licensing, and the
[customization guide](../docs/customization.md) for project settings.
